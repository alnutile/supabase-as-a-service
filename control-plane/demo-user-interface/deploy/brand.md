# SupaNet — Brand Guide

## Fonts (Google Fonts)

- **Schibsted Grotesk** — headings & body. Weights 400 / 500 / 600 / 700.
- **JetBrains Mono** — eyebrows, chips, small labels. Weights 400 / 500.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

Usage: Schibsted Grotesk for everything typographic; JetBrains Mono only for
uppercase mono labels (section eyebrows like `01 — SHARED & REMEMBERED`, chips, tags).

## Color palette

### Surfaces
| Token | Hex | Use |
|---|---|---|
| Background | `#FBFBF9` | Page background (warm off-white) |
| Panel | `#F6F7F4` | Card / inset panel fill |
| Panel alt | `#F3F5F0` | Section band fill |
| Border | `#E6E8E2` | Hairlines, card borders |

### Text
| Token | Hex | Use |
|---|---|---|

| Muted | `#5B665F` | Secondary text |
