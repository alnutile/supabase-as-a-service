# SupaNet Web Clipper (Chrome extension)

Save the page you are on into your workspace — as a bookmark, or as a clean
markdown artifact — and file it into a collection.

**Load it:** `chrome://extensions` → **Developer mode** on → **Load unpacked**
→ pick this folder. No build step: it is plain MV3 + ES modules, so the folder
you side-load is the same thing you zip for the Web Store.

**Connect it:** the popup asks for your Supabase project URL and a personal
connection token from **Settings → Connect Claude** in the app. Everything runs
as that token's owner.

Full reference — setup, how it talks to the workspace, permissions, the
extraction heuristic, troubleshooting, publishing — is in
[`docs/chrome-extension.md`](../docs/chrome-extension.md).

```
manifest.json        MV3 manifest (activeTab + scripting + storage, no host permissions)
popup/               The popup: connect once, then save the current tab
lib/parse.js         URL/title normalizing + the run-tool text parsers
lib/markdown.js      DOM -> Markdown
lib/extract.js       Find the article in a page, build the artifact body
lib/api.js           run-tool + artifacts REST client
lib/settings.js      chrome.storage.local wrapper
lib/*.test.js        Unit tests - run with `npm test` from the repo root
icons/               Generated by generate-icons.py from public/favicon.svg
```
